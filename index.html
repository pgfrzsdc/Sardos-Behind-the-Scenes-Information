Punishments
Timeouts
+

A timeout is a form of disciplinary action taken against a server member when that member breaks the server rules, the timeout restricts the user from joining voice channels, sending messages, or reacting to messages from other messages for a set amount of time.

Warnings
+

A warning is a form of notice to a server member when that server member breaks a minor server rule(s), and are usually given to a server member before a timeout if a rule is broken again, a warning could be given to a member by a staff member via either message or through a voice channel.

Soft Bans
+

A soft ban is when a user is banned from the server, restricting their access to it completely, but unlike a permanent ban, a soft ban gives the user a chance to appeal their ban, and return to the server.

Permanent Bans
+

A permanent ban is when a user is banned from the server, restricting their access to it completely and permanently, without the chance for appeal.
